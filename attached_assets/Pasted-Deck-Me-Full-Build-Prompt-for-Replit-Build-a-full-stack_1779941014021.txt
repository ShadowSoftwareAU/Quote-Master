Deck Me - Full Build Prompt for Replit
Build a full-stack business management platform called "Deck Me" for Australian decking tradespeople. It has two surfaces: a web admin dashboard and a React Native mobile app (Expo, iOS + Android). The platform covers the complete job lifecycle from quoting through to profit tracking.

Tech Stack:

Frontend web: React + TypeScript + Vite + Tailwind CSS + Shadcn/ui + Radix UI + Lucide icons
Mobile: React Native (Expo) with Expo Go for dev testing
Backend: Express.js API server
Database: PostgreSQL (Neon) + Drizzle ORM
Auth: Replit Auth (or email/password with JWT)
Payments: Stripe (subscriptions + automated revenue split payouts)
Forms: React Hook Form + Zod validation
Data fetching: TanStack Query
CORE FEATURE: Deck Calculator + BOM Engine
This is the heart of the app. The calculator takes deck dimensions and specifications, then auto-generates a complete Bill of Materials with line-item quantities and pricing.

Calculator Inputs:

Deck length and width (metres)
Deck board type (hardwood, composite, treated pine, etc.) with selectable profiles
Deck board gap spacing (user-adjustable, must appear on BOTH web and mobile)
Bearer size and spacing
Joist size and spacing (fix: bearer/joist navigation must work correctly, this was a known bug)
Subframe type (stumps, concrete slab, existing structure)
Fastener type (screws, hidden clips, etc.)
Structure checkboxes: Deck, Wall, Handrails, Stairs
Guardrails and Handrails options (e.g. "wall light end rails"), factored into the quote
Fencing: checkbox option with adjustable "fencing side" in specifications
Awning: checkbox option. If awning is built with the deck, auto-calculate cutouts in deck boards
Fascia options
BOM Output:

Full line-item list with quantities, unit prices, and totals
Multi-supplier price comparison (columns for Bunnings, Mitre 10, trade suppliers)
Trade cost vs retail cost separation: mobile app shows RETAIL ONLY (protects margin), web dashboard shows full trade cost visibility
CSV import for trade pricing (so the user can upload their supplier price lists)
Materials margin control beside the trade CSV import (set markup percentage)
Deposit Gating:

Itemised BOM/shopping lists are locked until a configurable deposit percentage is paid (e.g. 50%). Client pays deposit via Stripe, then gets access to the full material breakdown.
